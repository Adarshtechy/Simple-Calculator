# Simple Calculator

A clean and responsive web calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a simple and user-friendly interface.

## Features

- Basic arithmetic operations
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
  - Percentage (%)
- Responsive design
- Keyboard support
- Clear (AC) and Delete (DEL) buttons
- Clean and modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
Simple-Calculator/
│── index.html
│── style.css
│── script.js
│── README.md
```

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/Adarshtechy/Simple-Calculator.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
